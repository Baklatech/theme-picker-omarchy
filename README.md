# Каталог тем для Omarchy

Окно со всеми темами сообщества для [Omarchy](https://omarchy.org/): плитки с превью, основными цветами и названием. Отмечаете нужные темы и ставите их одной кнопкой, ненужную удаляете там же.

Каталог берётся с [omarchythemes.com](https://omarchythemes.com/), сами темы клонируются из своих git-репозиториев в `~/.config/omarchy/themes`, как при `omarchy theme install`.

Нужен Omarchy 4 или новее (окно — плагин Omarchy shell).

## Установка

```sh
git clone https://github.com/Gnome627/theme-picker-omarchy.git
cd theme-picker-omarchy
./install.sh
```

Запускать от обычного пользователя, `sudo` не нужен. Повторный запуск безопасен. Если окно после обновления показывает старую версию, перезапустите шелл: `omarchy restart shell`.

Зависимости: `python` (3.11+) и `git`. `imagemagick` нужен только чтобы вычислить цвета тем, у которых в репозитории нет палитры.

## Что получится

Окно открывается из меню Omarchy (Install → Style → Theme Catalog) или командой `theme-picker menu`. Горячей клавиши нет; если нужна, добавьте в `~/.config/hypr/bindings.lua`:

```lua
o.bind("SUPER + SHIFT + T", "Theme catalog", os.getenv("HOME") .. "/.local/bin/theme-picker menu")
```

На каждой плитке — превью, полоска цветов темы, название и статус:

- **installed** — тема установлена из каталога;
- **built-in** — тема входит в Omarchy;
- **current** — тема включена сейчас;
- **name taken** — папка с таким именем уже занята другой темой.

| Клавиша | Действие |
|---|---|
| стрелки, PageUp/PageDown | перемещение по плиткам |
| Пробел или клик | отметить тему для установки |
| Enter | установить отмеченные (если ничего не отмечено — выделенную) |
| Delete | удалить выделенную тему, второе нажатие или Enter подтверждает |
| набор текста | поиск по названию |
| Tab | показать только установленные |
| F5 | обновить каталог |
| Esc | сбросить поиск, затем закрыть |

Окно говорит по-русски в русской локали и по-английски во всех остальных.

## Как это работает

- **Установка не включает тему.** `omarchy theme install` применяет каждую тему сразу, и при пяти выбранных рабочий стол переключился бы пять раз. Включается тема обычным переключателем тем Omarchy.
- **Удаляются только темы, склонированные из git.** Встроенные темы принадлежат пакету omarchy, а тему, написанную руками, заново поставить неоткуда — их окно не трогает.
- **Цвета** читаются из `colors.toml` или `alacritty.toml` в репозитории темы. Если этих файлов нет, палитра вычисляется из превью.
- **Кэш** превью и палитр лежит в `~/.cache/theme-picker` (около 20 МБ). Первое открытие докачивает его примерно полминуты, плитки заполняются по ходу. Список тем обновляется раз в час или по F5.
- Клоны проходят ту же проверку адреса (`omarchy-git-url-check`), что и штатная установка, а файлы, которые теме из репозитория иметь нельзя, Omarchy отбрасывает в момент включения темы.

Вся работа — в `~/.local/bin/theme-picker`; окно только рисует его каталог и вызывает его команды:

```sh
theme-picker catalog [--refresh]   # каталог в JSON
theme-picker sync                  # докачать превью и палитры
theme-picker install <url>...      # склонировать темы
theme-picker remove <slug>         # удалить тему, поставленную из git
theme-picker menu                  # открыть или закрыть окно
```

## Удаление

```sh
./uninstall.sh
```

Убирает скрипт, плагин, кэш и строку меню. Установленные темы остаются.
