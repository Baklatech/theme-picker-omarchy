# theme-picker-omarchy

Все темы сообщества Omarchy плитками в одном окне. Отметил, поставил, готово.

```bash
git clone https://github.com/Baklatech/theme-picker-omarchy && cd theme-picker-omarchy && ./install.sh
```

Открывается из меню: Install → Style → Theme Catalog. Нужен Omarchy 4+. [Подробно](docs/guide.md).
